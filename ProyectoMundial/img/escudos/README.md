# Escudos de las federaciones

Acá van los logos oficiales de cada federación (no la bandera del país).

Nombre de archivo: el código de 2 letras del país + .png. Por ejemplo, para
Japón (code "jp"):

    img/escudos/jp.png

Si el archivo no existe todavía, la carta cae automáticamente en la bandera
del país como respaldo (no se rompe nada), y si tampoco hay bandera, en el
ícono genérico.

Para descargarlos automáticamente: `node descargar-escudos.cjs` desde la raíz
del proyecto (mismo mecanismo que descargar-fotos.cjs, usando Wikipedia).
