# Fotos de jugadores

Coloquen acá las fotos de cada jugador con el nombre exacto del ID de su carta.

Ejemplo: la barajita de Cristiano Ronaldo tiene id `POR-09` (Portugal, jugador 9),
así que la imagen debe llamarse:

    img/jugadores/POR-09.jpg

Formato recomendado: .jpg, relación de aspecto 3:4 (vertical), fondo recortado.

Si el archivo no existe todavía, la barajita muestra automáticamente el
ícono según el rol (arquero/defensa/mediocampista/delantero) — no rompe nada
dejar fotos pendientes, se pueden ir agregando de a poco.

Para ver el ID exacto de cada carta: abran la consola del navegador y
escriban `ALBUM_DATA` o revisen data.js (siglaPais + número de jugador).
